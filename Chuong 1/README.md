# Chương 1 — EduHub

Ứng dụng console quản lý câu lạc bộ hiến máu, thành viên, sự kiện, đăng ký và điểm danh.

## Chạy chương trình

```powershell
dotnet run --project EduHub.Ch01.csproj
```

## Cấu trúc

- `Domain/`: các mô hình và quy tắc nghiệp vụ.
- `Program.cs`: ví dụ chạy ứng dụng.
- `docs/`: user stories và sơ đồ lớp.
